# Datasets

What data this project uses, where it comes from, what its terms allow, and how to prepare it locally.

**In short:**
- **No training or evaluation dataset is stored in this repository.** For each one, the redistribution terms are missing or unresolved, and the handwriting set is also 5.2 GB.
- **What is included:** the fonts (licence permits), small generated test inputs, and a **SHA-256 manifest of every dataset file the project used** (`data/manifests/datasets.json`).
- **Checking a local copy:** `tools/check_datasets.py` checks a locally prepared copy against that manifest.
- **Tests need no dataset:** every test generates its inputs in memory.

## Overview

| Dataset | Used for | In this repo? | Terms | Size |
|---|---|---|---|---|
| IIIT-INDIC-HW-WORDS, Tamil (handwritten words) | training (all four experiments); handwriting evaluation | no | **none published** on the CVIT page or the Hugging Face card; redistribution not granted | 5.2 GB (12 Parquet files), 103,518 images |
| Word list `tamil_correction_vocabulary.json` (522,495 word forms with frequencies) | synthetic printed words in experiments 001, 002-A, 002-B | no | built from Project Madurai texts and the Senthamizh corpus (MIT / Apache-2.0 stated, possible CC BY-NC parts); the combined terms are **not established** | 19.9 MB |
| Synthetic validation set (6,000 word images) | synthetic-print evaluation in the checkpoint reports | no | generated by this project, but from the word list above | 85 MB |
| Tamil Wikipedia dump | optional input of `tools/build_wordlist.py` | no | CC BY-SA 4.0 (Wikimedia); redistributable with attribution, but large and versioned | 277 MB |
| Fonts (15 families) | synthetic generator, tests | **yes**, `assets/fonts/` | SIL Open Font License 1.1; licence texts included | 6.5 MB |
| Generated regression inputs (26 word images, 6 pages, and their manifest) | the development workspace's default-output comparison | no (`diagnostic_fixtures/` is ignored; the tests generate their own inputs) | generated by this project with the fonts above | 5.7 MB |
| Generated experiment pages | segmentation experiments | no (regenerable) | generated | about 540 MB, regenerated by `dev_tools/*_experiments.py` |

**Not used by current code, and not published:** an isolated handwritten Tamil character set (`data/chars_hpl`, 77,609 images); an earlier small vocabulary (`data/vocab`); a larger merged word list (`tamil_words_merged.json`); the raw text corpora behind the word list (460 MB).

**Protected and never published:** the project's real-page pilot (`real_docs/`) and its development pages (`development_pages/`), including annotations. The application refuses them by fingerprint (`docs/SECURITY_AND_PRIVACY.md`). The development pages carry per-page redistribution statuses (`pageocr/rights.py`); some are internal-only.

## 1. IIIT-INDIC-HW-WORDS, Tamil

- **Creators:** Santhoshini Gongidi and C. V. Jawahar, Centre for Visual Information Technology (CVIT), IIIT Hyderabad.
- **Project page:** https://cvit.iiit.ac.in/research/projects/cvit-projects/iiit-indic-hw-words
- **Publication** (as listed on the CVIT page): Santhoshini Gongidi, C. V. Jawahar, *INDIC-HW-WORDS: A Dataset for Indic Handwritten Text Recognition*, International Conference on Document Analysis and Recognition (ICDAR) 2021.
- **Copy used by this project:** the Parquet conversion `c3rl/IIIT-INDIC-HW-WORDS-Tamil` on the Hugging Face Hub. 12 files: train 8, validation 2, test 2. 75,736 / 11,598 / 16,184 images.
- **Terms:** checked on 2026-10-11. Neither the CVIT page nor the Hugging Face card states a licence or terms of use, so no right to redistribute is granted and the data is not in this repository. Check the current terms yourself before use, and cite the publication above.

**Preparation**, with no login needed for a public dataset. Download the Parquet files yourself, by your preferred method, into the expected place:

```
external/IIIT-INDIC-HW-WORDS-Tamil/data/train-0000{0..7}-of-00008.parquet
external/IIIT-INDIC-HW-WORDS-Tamil/data/validation-0000{0,1}-of-00002.parquet
external/IIIT-INDIC-HW-WORDS-Tamil/data/test-0000{0,1}-of-00002.parquet
```

Then convert and verify:

```powershell
python tools/check_datasets.py --only iiit_hw_parquet                        # same files as the project used?
python tools/import_hf_parquet.py --src external/IIIT-INDIC-HW-WORDS-Tamil --inspect
python tools/import_hf_parquet.py --src external/IIIT-INDIC-HW-WORDS-Tamil --out data/real/iiit_hw --name iiit_hw
python tools/check_datasets.py --only iiit_hw_converted                      # manifests identical to the project's?
python tools/check_split.py --help                                           # split audit (val 11,598 vs official 11,597)
```

**Result:** `data/real/iiit_hw/{train,val,test}/*.jpg` and `manifest_{train,val,test}.jsonl`, with relative paths, plus `import_report.txt`. Image bytes are written unchanged; labels are NFC-normalised; labels with characters outside `src/charset.py` are left out and listed in the report.

**Known properties:**
- 85.3 % of the test labels also occur among the training labels.
- Six test images are byte-identical to training images (`tools/check_split.py`).

## 2. Word list for synthetic print

- **What it is:** `data/text_corpus/tamil_correction_vocabulary.json`, a JSON object `{"word": frequency}` with 522,495 entries. SHA-256 `3f19ac2db418d3061162acfd978463b3f3a0c21652e4968c8383fa2e24a2241a`; `tools/pretrain_check.py` asserts this hash.
- **Sources:**
  - Project Madurai e-texts: no terms stated in the project's integration report;
  - the Senthamizh corpus: its README states Apache-2.0, its integration report MIT, and it warns that some integrated content may be CC BY-NC.
- **Why it is excluded:** the combined terms of a list derived from these sources were not established.

**A substitute word list** that you have the right to use can be built from your own Tamil texts or a Tamil Wikipedia dump:

```powershell
python tools/build_wordlist.py --txt-dir <folder of .txt files> --out data/text_corpus/my_words.json
python tools/build_wordlist.py --help          # including --wiki <tawiki-*-pages-articles.xml.bz2>
```

Then point the configuration's `vocab:` line at it. A model trained with a substitute is a model of the same kind, not the same model, and `tools/pretrain_check.py` will report the hash assertion as failed. That is expected.

## 3. Synthetic validation set

6,000 images (3,000 modern-print style, 3,000 old-print style) with labels, used for the synthetic CER in the checkpoint reports. Regenerate it with the original word list:

```powershell
python tools/synth_export.py --vocab data/text_corpus/tamil_correction_vocabulary.json --out data/synth_val --n-modern 3000 --n-old 3000 --seed-base 900000000
python tools/check_datasets.py --only synth_val
```

With a substitute word list the set differs, and the manifest check will say DIFFERENT. Scores on it are then not comparable to the recorded ones.

## 4. Tamil Wikipedia dump (optional)

`external/tawiki/tawiki-latest-pages-articles.xml.bz2`, from https://dumps.wikimedia.org/tawiki/ (CC BY-SA 4.0 and GFDL; attribution required). The project's copy has SHA-256 `bf044b7b…aa64cb7` (full value in the manifest). "latest" changes over time, so a newer dump gives a different hash and a different word list.

## 5. Fonts

`assets/fonts/`: 29 font files of 15 families (Anek Tamil, Arima, Baloo Thambi 2, Catamaran, Coiny, Hind Madurai, Karla Tamil Inclined and Upright, Kavivanar, Meera Inimai, Mukta Malar, Noto Sans Tamil, Noto Serif Tamil, Pavanam, Tiro Tamil). All are under the SIL Open Font License 1.1, with each family's licence text (`OFL_*.txt`) next to the fonts. See `THIRD_PARTY_NOTICES.md`.

## Folder layout and Git

`data/` and `external/` are ignored by Git, except `data/README.md` and `data/manifests/`. Prepared data therefore cannot be committed by accident. Expected layout:

```
external/IIIT-INDIC-HW-WORDS-Tamil/data/*.parquet       downloaded
data/real/iiit_hw/{train,val,test}/  manifest_*.jsonl     tools/import_hf_parquet.py
data/text_corpus/tamil_correction_vocabulary.json        word list (or your substitute)
data/synth_val/images/  manifest.jsonl                   tools/synth_export.py
data/manifests/datasets.json                             in the repository: expected sizes and hashes
```

## Ground truth

- Labels come from the dataset's own annotations or from the generator.
- **Model output is never used as ground truth.**
- The real-page pilot's references were produced by an AI assistant and not verified by a person, so they are not used as accuracy evidence.
